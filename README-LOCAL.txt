TasksMon Task Creator - Local Package

1. Make sure Google Chrome is installed on this computer.
2. Double-click start-web.bat.
3. Keep the "TasksMon Web Server" window open while using the app.

The web page opens automatically at http://localhost:3000.

No Node.js or npm installation is needed for this package. The included
runtime and libraries are used by start-web.bat.

To stop the application, close the "TasksMon Web Server" window.
